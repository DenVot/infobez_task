# Учебный CTF: отправка формы

Статическая страница для учебного стенда курса кибербезопасности.

В `index.html` оба поля содержат заглушку `<word>` (в HTML записана как `&lt;word&gt;`). Пока заглушка присутствует хотя бы в одном поле, запрос не отправляется. После замены обоих значений на одинаковый тестовый пароль страница при открытии автоматически отправляет форму:

- URL: `https://cats.is-course.ru/settings`
- Метод: `POST`
- Тип тела: `application/x-www-form-urlencoded`
- Поля: `password` и `confirm-password`

После отправки браузер переходит на ответ учебного стенда. Страница не подтверждает успешную смену пароля. Передача сессионных cookies зависит от SameSite и других ограничений браузера; сервер также может проверять CSRF-токен или Origin.

## Публикация в GitHub Pages

Сборка и зависимости не требуются.

1. В репозитории откройте **Settings → Pages**.
2. В **Build and deployment → Source** выберите **Deploy from a branch**.
3. Выберите ветку **main**, каталог **/ (root)** и нажмите **Save**.
4. Дождитесь завершения публикации. Ожидаемый адрес: https://denvot.github.io/infobez_task/

Публикация в рамках подготовки не запускалась. Исходный код публичен: используйте только одноразовое тестовое значение.
